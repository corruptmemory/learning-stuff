Difference-in-Differences

How to measure causal effects when you can't run an experiment

You want to know: does hosting the Olympics cause a country to win more medals? You can't randomly assign who hosts. You can't rewind time. You have observational data and a question about causation. This is exactly where Difference-in-Differences (DiD) lives.

The core idea is deceptively simple. You observe two groups over time — one that gets "treated" (hosts the Olympics) and one that doesn't. You compare how much each group changed, and attribute the difference in those changes to the treatment:

$$\hat{\tau}_{\text{DiD}} = \bigl(\bar{Y}^{\text{treat}}_{\text{after}} - \bar{Y}^{\text{treat}}_{\text{before}}\bigr) - \bigl(\bar{Y}^{\text{ctrl}}_{\text{after}} - \bar{Y}^{\text{ctrl}}_{\text{before}}\bigr)$$

That's it. But the power — and the danger — is all in the assumptions hiding behind that simple formula. Let's build the intuition.

Notation Reference
SymbolNameMeaning
$Y_{i,t}$ Observation Outcome for unit $i$ at time $t$. This is what the dots on the charts show — raw data, one per group per time period.
$\bar{Y}$ Sample mean Average of observations. The bar means "mean" (same convention as physics). Superscripts and subscripts specify which mean.
$\bar{Y}^{\text{treat}}_{\text{after}}$ Group-period mean Average outcome for the treatment group in the post-treatment period. Computed by averaging all treatment-group dots to the right of the treatment line.
$\bar{Y}^{\text{ctrl}}_{\text{before}}$ Group-period mean Average outcome for the control group in the pre-treatment period. Similarly for other superscript/subscript combinations.
$\tau$ Treatment effect The true causal effect of treatment. This is the unknown quantity we're trying to estimate. In econometrics, $\tau$ is conventional for treatment effects (where a physicist might expect $\Delta$).
$\hat{\tau}$ Estimated treatment effect Our estimate of $\tau$ from data. The hat ($\hat{}$) means "estimated" — same convention as physics. $\hat{\tau}_{\text{DiD}}$ is a single scalar, not a per-time-point value.
$\hat{\tau}_{\text{DiD}}$ DiD estimator The difference-in-differences estimate: $(\bar{Y}^{\text{treat}}_{\text{after}} - \bar{Y}^{\text{treat}}_{\text{before}}) - (\bar{Y}^{\text{ctrl}}_{\text{after}} - \bar{Y}^{\text{ctrl}}_{\text{before}})$. One number summarizing the causal effect.

Reading the charts: The plotted dots are $Y_{i,t}$ (raw observations). The $\bar{Y}$ values are what you'd get by averaging dots within a region (group × period). $\hat{\tau}$ collapses all of that into a single number shown in the readout below each chart.

Sandbox 2: Why Not Just Compare Before/After?

There are simpler ways to estimate the treatment effect. Why not just compare the treatment group before and after? Or compare treatment to control at the end? Each approach makes a different mistake. DiD avoids both.

The three estimates below use the same data. Watch which ones get the right answer — and which ones break — as you change the parameters.

So DiD works when the alternatives don't. But when does DiD itself break?

Sandbox 3: The Parallel Trends Assumption

DiD's crucial assumption: in the absence of treatment, both groups would have followed parallel trends. You can never prove this (the counterfactual doesn't exist), but you can check if pre-treatment trends are parallel — and you can see what happens when they're not.

Sandbox 5: The Code — R and Python Side by Side

Everything you just explored with sliders reduces to a few lines of code. Here's the same DiD analysis expressed in both R and Python — not as a language tutorial, but as a Rosetta Stone. Each block does the same thing; the concept is the anchor, the syntax is just dialect.

The Basic DiD Estimate (what Sandbox 1 computes)

Group means, differenced twice: $\hat{\tau} = (\bar{Y}^T_{post} - \bar{Y}^T_{pre}) - (\bar{Y}^C_{post} - \bar{Y}^C_{pre})$

R
# Group means approach
did_estimate <- mean(df$y[df$treat == 1 & df$post == 1]) -
               mean(df$y[df$treat == 1 & df$post == 0]) -
              (mean(df$y[df$treat == 0 & df$post == 1]) -
               mean(df$y[df$treat == 0 & df$post == 0]))

# Equivalent regression (more common in practice)
library(fixest)
model <- feols(y ~ treat:post | id + time, data = df)
#                ^^^^^^^^^^   ^^^^^^^^^^
#                interaction   fixed effects for unit and time
#                = the DiD     (absorb level differences + trends)
Python
# Group means approach
import pandas as pd
did_estimate = (df.query('treat==1 & post==1')['y'].mean() -
                df.query('treat==1 & post==0')['y'].mean() -
               (df.query('treat==0 & post==1')['y'].mean() -
                df.query('treat==0 & post==0')['y'].mean()))

# Equivalent regression
import pyfixest as pf
model = pf.feols("y ~ treat:post | id + time", data=df)
#                  ^^^^^^^^^^      ^^^^^^^^^^
#                  interaction      fixed effects for unit and time
#                  = the DiD        (absorb level differences + trends)
Key mapping: The feols() function exists in both ecosystems — R's fixest package and Python's pyfixest (which deliberately mirrors the R API). The formula syntax is identical: y ~ treat:post | id + time. The | separates the model from the fixed effects. This is the form you'll see in Cremieux's code.

Two-Way Fixed Effects (what Sandbox 4 does under the hood)

With multiple countries hosting at different times, DiD becomes a two-way fixed effects (TWFE) regression: absorb country-level and time-level variation, estimate the treatment coefficient.

R
library(fixest)

# TWFE regression for Olympic hosting effect
model <- feols(
  medals ~ hosting | country + year,
  data = olympics
)
# hosting coefficient = DiD estimate of
# the causal effect of hosting on medals

summary(model)
# Shows: coefficient, std error, t-stat, p-value

# Decomposition: control for delegation size
model2 <- feols(
  medals ~ hosting + delegation_size | country + year,
  data = olympics
)
# Now 'hosting' is the residual effect
# AFTER accounting for larger delegations
Python
import pyfixest as pf

# TWFE regression for Olympic hosting effect
model = pf.feols(
    "medals ~ hosting | country + year",
    data=olympics
)
# hosting coefficient = DiD estimate of
# the causal effect of hosting on medals

model.summary()
# Shows: coefficient, std error, t-stat, p-value

# Decomposition: control for delegation size
model2 = pf.feols(
    "medals ~ hosting + delegation_size | country + year",
    data=olympics
)
# Now 'hosting' is the residual effect
# AFTER accounting for larger delegations
Notice: The formula strings are identical between R and Python. This is by design — pyfixest was built as a Python port of R's fixest. If you can read Cremieux's R formula, you can paste it into Python and it (mostly) just works.

Testing Parallel Trends (the assumption from Sandbox 3)

You can't prove parallel trends, but you can check pre-treatment trends. An "event study" plot shows the treatment effect at each time period relative to the treatment date. Pre-treatment coefficients should be near zero.

R
library(fixest)

# Event study: estimate effect at each
# period relative to treatment
model_es <- feols(
  medals ~ i(rel_year, ref = -1) | country + year,
  data = olympics
)
#         ^^^^^^^^^^^^^^^^^^^^^^^^
#         interaction of relative-year dummies
#         ref = -1 means "1 period before
#         treatment is the baseline"

# Plot it — fixest has built-in event study plots
iplot(model_es)
# Pre-treatment coefficients near 0?
# → parallel trends plausible
Python
import pyfixest as pf

# Event study: estimate effect at each
# period relative to treatment
model_es = pf.feols(
    "medals ~ i(rel_year, ref=-1) | country + year",
    data=olympics
)
#           ^^^^^^^^^^^^^^^^^^^^^^^^
#           interaction of relative-year dummies
#           ref=-1 means "1 period before
#           treatment is the baseline"

# Plot it — pyfixest also has event study plots
model_es.iplot()
# Pre-treatment coefficients near 0?
# → parallel trends plausible
The event study plot is the standard "show your work" diagram in any DiD paper. When you see a plot with coefficients bouncing around zero before treatment and jumping up after — that's this. Cremieux shows exactly this pattern in his article.
